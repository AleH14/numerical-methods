# numerical-methods

This repository contains implementations of the main numerical methods for:

- **Solving Nonlinear Equations** of one or more variables
- **Interpolation**
- **Differentiation**
- **Integration**
- **Differential Equations**

## ⚠️ Important Notice

Some items in this repository were used outside the university's exam environment.

## Overview

This project provides a comprehensive collection of MATLAB implementations for fundamental numerical analysis techniques. These methods are essential for solving mathematical problems that cannot be solved analytically or require computational approaches.

## 📋 Topics Covered

### Nonlinear Equations
Algorithms for finding roots of equations with one or multiple variables, including:
- Bisection method
- Newton-Raphson method
- Secant method
- And more

### Interpolation
Methods for estimating values between known data points:
- Polynomial interpolation
- Lagrange interpolation
- Newton's divided differences

### Differentiation
Numerical techniques for computing derivatives:
- Forward, backward, and central differences
- Higher-order derivatives

### Integration
Methods for numerical integration:
- Trapezoidal rule
- Simpson's rules
- Gaussian quadrature

### Differential Equations
Techniques for solving ordinary differential equations:
- Euler's method
- Runge-Kutta methods
- Multi-step methods

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/AleH14/numerical-methods.git
cd numerical-methods
```

2. Open MATLAB and navigate to the repository directory.

3. Add the repository to your MATLAB path:
```matlab
addpath(genpath(pwd))
```
